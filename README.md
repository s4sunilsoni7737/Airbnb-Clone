🌍 Airbnb Clone – MERN Stack Project (Passport.js Auth, Cloudinary, Bootstrap)
A full-stack Airbnb Clone built using the MERN stack with Passport.js authentication, Cloudinary for image uploads, and Bootstrap for the responsive UI. Users can register, log in, add property listings with images, and post reviews.

🚀 Features
🔐 Authentication & Authorization

User login/signup using Passport.js (Local Strategy)

Session-based secure authentication

🏠 Property Listings

Add, edit, and delete listings

Upload images using Cloudinary

Store location, title, description, and price

✍️ Reviews System

Users can post reviews on listings

Each property displays all reviews

🧾 User Dashboard

View and manage user's own listings and reviews

📱 Responsive UI

Built with Bootstrap for mobile-first experience

🛠️ Tech Stack

Layer	Technology
Frontend	React.js, Bootstrap
Backend	Node.js, Express.js
Database	MongoDB, Mongoose
Auth	Passport.js (Local Strategy)
Image Upload	Cloudinary + Multer
Deployment	Render (frontend & backend), MongoDB Atlas
